# Glossary

**Project:** Freelance Marketplace Escrow, Milestone Release, Dispute and Fee-Tier Engine

| Term | Description |
|---|---|
| Client | The person who hires a freelancer and pays for the project. |
| Freelancer | The person who performs the project work for the client. |
| Project | A job or contract agreed upon between a client and a freelancer. |
| Escrow | Money held securely until the agreed conditions for payment are fulfilled. |
| Milestone | A specific stage of a project with an agreed amount and due date. |
| Funding | Depositing money into escrow for a project or milestone. |
| Release | Transferring the approved milestone payment to the freelancer after applicable deductions. |
| Refund | Returning escrow money to the client. |
| Submission | The freelancer submitting completed milestone work for client review. |
| Approval | The client's acceptance of submitted milestone work. |
| Revision | A request from the client to make changes to submitted work. |
| Auto-approval | Automatic approval and release when the client does not take action within the specified period. |
| Dispute | A disagreement between the client and freelancer regarding a milestone. |
| Evidence | Information or documents submitted by the parties to support their position in a dispute. |
| Mediation | A stage in which the parties attempt to resolve a dispute before arbitration. |
| Arbitration | A formal decision-making process used to resolve an unresolved dispute. |
| Service Fee | The fee deducted from the freelancer's payment according to the applicable fee tier. |
| Processing Fee | The fee charged to the client when funding escrow. |
| TDS | Tax Deducted at Source, deducted according to the specified tax rules. |
| Withdrawal | Transferring available funds from the freelancer's account. |
| KYC | Know Your Customer verification used to verify a user's identity. |
| Lifetime Billing | The cumulative amount released for a freelancer-client relationship. |
| Ledger | A record of financial transactions, including funding, releases, fees and refunds. |
| Inactivity | A period during which no project event occurs. |
