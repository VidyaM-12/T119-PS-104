## Project Description

The Freelance Marketplace Escrow, Milestone Release, Dispute and Fee-Tier Engine is a command-driven application developed using Python.

The system manages freelance projects, milestone funding, escrow payments, milestone submissions, approvals, revisions, automatic approvals, disputes, arbitration, cancellations and freelancer withdrawals.

It also calculates freelancer service fees, client processing fees and Tax Deducted at Source (TDS) according to the specified business rules.

## Technology Stack

- Programming Language: Python
- Code Editor: Visual Studio Code
- Input Format: CSV and command files
- Version Control: Git and GitHub
- Testing: Python unittest

## Project Objective

To develop a reliable payment management engine that automates the financial and workflow operations of a freelance marketplace while ensuring that all specified business rules are followed.
